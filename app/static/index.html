How to read this result

Each day is compared with prior observations. The detector uses recent same-weekday medians where there is enough history, then falls back to recent prior days. It does not use future rows to set a baseline.

Alerts require a minimum dollar change, percentage change, and robust spread threshold. Three or more consecutive alert days are grouped as a sustained increase.
